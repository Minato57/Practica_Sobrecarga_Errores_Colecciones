# Práctica de Java: Sobrecarga, Colecciones y Manejo de Errores

Este repositorio contiene una serie de prácticas y ejercicios de programación en **Java** realizados por **Aaron Valentino Gutierrez Vega**. El objetivo principal de estos proyectos es afianzar los conceptos fundamentales de la Programación Orientada a Objetos (POO).

## 📂 Estructura del Repositorio

El proyecto está dividido en tres áreas principales (como proyectos independientes de NetBeans/Apache Ant):

### 1. Sobrecarga de Métodos (`Sobrecarga de Métodos/`)
Contiene ejercicios prácticos que demuestran el polimorfismo mediante la **sobrecarga de métodos**. 
- Se implementan múltiples métodos con el mismo nombre (ej. `sumar`) pero con diferentes tipos o cantidad de parámetros (ej. sumar dos `int`, tres `int`, o dos `double`).

### 2. Colecciones (`Coleciones/`)
Enfocado en el uso y manejo de la API de Colecciones de Java (Collections Framework).
- Aborda la creación, manipulación e iteración de estructuras de datos dinámicas como Listas (ej. `ArrayList`), esenciales para el manejo de datos en memoria en tiempo de ejecución.

### 3. Manejo de Errores (`Manejo de Errores/`)
Prácticas orientadas a la programación robusta mediante el control de excepciones.
- Uso de bloques `try-catch` y la palabra reservada `throw`/`throws` para capturar errores previstos e imprevistos, evitando que la ejecución del programa se detenga abruptamente.

## 🛠️ Tecnologías y Entorno

- **Lenguaje:** Java
- **IDE Recomendado:** Apache NetBeans (los proyectos cuentan con la carpeta `nbproject`) o cualquier IDE compatible con estructuras de Java convencionales (Eclipse, IntelliJ IDEA, VS Code).
- **Herramienta de Construcción:** Apache Ant (`build.xml`).

## 🚀 Cómo Ejecutar los Proyectos

1. Clona o descarga el contenido de esta carpeta.
2. Abre tu IDE de preferencia (ej. NetBeans).
3. Selecciona **File > Open Project** y navega hasta la carpeta del proyecto específico que deseas revisar (por ejemplo, `Coleciones`).
4. Haz clic derecho sobre el proyecto en el explorador y selecciona **Run** (o ejecuta la clase principal `Main.java` correspondiente).
